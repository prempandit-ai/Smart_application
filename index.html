    PROJECT OVERVIEW

    How the simulation works

    This dashboard models the control loop from an ESP32 MicroPython refrigerator project. Adjust the sensor reading and door state to see how the controller responds in real time.

    °C

    DHT22

    Simulated temperature measurement. A failure retains the last valid reading.

    ▯

    Door sensor

    Tracks the refrigerator door and starts a 30-second open alarm timer.

    ↯

    Relay

    Turns simulated cooling on above 8°C and off at or below 4°C.

    ♬

    Buzzer

    Browser generated beep tone for active alarms; mute affects audio only.

    ◷

    JavaScript timer

    Runs the simulated main control loop approximately once per second.

    ◖

    Web Audio API

    Creates the software buzzer after a user gesture, subject to browser audio support.

    ✦

    Working principle The slider supplies the simulated sensor value. The JavaScript control loop applies relay hysteresis, checks the high-temperature and door timers, updates the chart and log, then sounds the buzzer when either alarm is active.
